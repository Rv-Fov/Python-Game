##  Deskripsi Project

Space Field Adventure adalah mini game bertema space shooter yang dikendalikan menggunakan gerakan tangan secara real-time melalui webcam. Pemain mengontrol pesawat luar angkasa dengan menggerakkan tangan di depan kamera dan menembakkan peluru menggunakan gesture tertentu.

Proyek ini dikembangkan menggunakan Python dan OpenCV tanpa menggunakan game engine maupun framework game. Sistem deteksi tangan memanfaatkan segmentasi warna kulit (skin color detection) pada ruang warna HSV untuk melacak posisi tangan pemain. Hasil deteksi digunakan untuk mengontrol pergerakan pesawat dan menghasilkan aksi menembak.
